
# Contributing Guide

Thank you for your interest in improving College Assistant Voice Chatbot.

## How to Contribute

1. Check existing issues before reporting a new problem.
2. Create a separate branch for each change.
3. Keep pull requests focused on one improvement.
4. Explain what changed and why in the pull request description.
5. Test the affected functionality before submitting changes.

## Reporting Bugs

When reporting a bug, include:
- A clear description of the problem
- Steps to reproduce it
- Expected and actual results
- Relevant error messages, with sensitive information removed

## Security

Never commit API keys, passwords, access tokens, or `.env` files.
Keep credentials in environment variables and report security concerns responsibly.
